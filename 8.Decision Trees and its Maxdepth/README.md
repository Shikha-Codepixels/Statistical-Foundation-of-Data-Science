# Objective

To build a Decision Tree Classifier using the Pima Indians Diabetes dataset and understand the concepts of Entropy, Information Gain and Gini Index.

# Dataset

Dataset: Pima Indians Diabetes Dataset

Source: Kaggle

Target Variable: Outcome

Features: Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction and Age.

# Tasks Performed

Dataset loading and preprocessing.

Feature selection (independent and dependent variables).

Training and testing data split.

Decision Tree Classifier implementation using Scikit-learn.

Decision Tree visualization.

Calculation of Entropy, Information Gain and Gini Index.

Root node selection and interpretation.

# Libraries Used

Pandas

NumPy

Matplotlib

Seaborn

Scikit-learn

# Conclusion

Successfully implemented and visualized a Decision Tree Classifier for diabetes prediction. Explored Entropy, Information Gain and Gini Index to understand feature selection and decision-making in classification.
