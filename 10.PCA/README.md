# Objective

To perform exploratory data analysis, visualization, covariance analysis, and dimensionality reduction using Principal Component Analysis (PCA) on the Wine dataset.

# Dataset

Dataset: Wine Dataset

Source: Scikit-learn

Target Variable: Wine Class (Output)

Features: Chemical properties of wine samples.

# Tasks Performed

Displaying basic statistical information using describe().

Creating boxplots to compare features across output classes.

Visualizing relationships between two variables using scatterplots.

Computing and visualizing the covariance matrix using a heatmap.

Applying data scaling to standardize features.

Applying Principal Component Analysis (PCA).

Visualizing class separation using principal components.

# Libraries Used

Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

# Conclusion

Successfully performed exploratory data analysis and visualization on the Wine dataset. Applied feature scaling and Principal Component Analysis to reduce dimensionality and visualize class separation using principal components.
