# Objective

To perform statistical analysis on the Teaching Ratings dataset using Python and explore relationships between instructor characteristics and student evaluation scores.

# Dataset

File: TeachingRatings.csv

Observations: 463

Key features: Gender, Age, Beauty Rating, Student Evaluation.

# Tasks Performed

Data preprocessing and exploration.

Linear Regression analysis.

One-Way ANOVA.

Comparison of beauty ratings across age groups.

Statistical interpretation of results.

# Libraries Used

Pandas

NumPy

Matplotlib

Seaborn

Statsmodels

# Conclusion

Successfully applied statistical techniques, including Linear Regression and One-Way ANOVA, to examine relationships between instructor characteristics and student evaluation ratings.
