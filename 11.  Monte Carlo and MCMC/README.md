# Objective

To apply Bayesian analysis and Markov Chain Monte Carlo (MCMC) methods to the Sunspot dataset and study variations across solar cycles.

# Dataset

Dataset: Sunspot Dataset

Observations: 3,239

Features: 8

Solar Cycles: 23

# Tasks Performed

Loading and exploring the Sunspot dataset.

Performing data preprocessing and exploratory analysis.

Identifying and grouping observations across solar cycles.

Applying Bayesian analysis using MCMC sampling.

Estimating model parameters for individual solar cycles.

Analyzing MCMC sampling results and acceptance rates.

Visualizing and interpreting the results across solar cycles.

# Libraries Used

NumPy, Pandas, Matplotlib, SciPy.

# Conclusion

Successfully applied Bayesian MCMC methods to the Sunspot dataset to analyze solar cycle variations and estimate parameters. Explored sampling behavior and interpreted the results across 23 solar cycles.
