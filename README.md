# About This Repository

This repository contains practical implementations and coursework related to Statistical Foundations of Data Science. It focuses on understanding fundamental statistical concepts, applying statistical methods, exploring datasets, and interpreting results using Python.

The repository includes hands-on exercises covering statistical analysis, data visualization, hypothesis testing, machine learning techniques, and probabilistic methods.

# Topics Covered

Python Libraries: NumPy and Pandas

Descriptive Statistics

Data Exploration and Visualization

Hypothesis Testing

T-Test and ANOVA

Regression Analysis

Decision Tree Classification

K-Nearest Neighbors (KNN)

Principal Component Analysis (PCA)

Monte Carlo Simulation and MCMC

Metropolis Algorithm

Deterministic Modelling

# Tools and Technologies

Language: Python

Environment: Google Colab

Libraries: NumPy, Pandas, Matplotlib, Seaborn, SciPy, Scikit-learn, Statsmodels
