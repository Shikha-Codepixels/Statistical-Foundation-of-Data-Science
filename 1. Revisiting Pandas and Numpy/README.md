# Objective
The objective of this practical is to revise and apply the fundamental concepts of Pandas and NumPy using a student dataset containing both numerical and categorical data.

# What I Did
In this practical, I first created a raw student dataset containing student names, gender, department, and marks in Mathematics, Physics, and Chemistry. The raw data was then converted into a Pandas DataFrame for easier organization and manipulation.
After creating the DataFrame, I extracted the numerical columns and converted them into a NumPy array. I then examined the array using NumPy to determine its shape, size, and number of dimensions.
Various NumPy operations were performed on the numerical data, including:
-	Matrix addition
-	Matrix subtraction
-	Element-wise multiplication
-	Matrix transpose
-	Matrix product
-	Matrix inverse

Since the original marks dataset was not a square matrix, a suitable 3×3 matrix obtained through matrix multiplication was used to demonstrate the inverse operation.
Finally, the categorical columns Gender and Department were converted into numerical values using label encoding. This demonstrates how categorical information can be transformed into a numerical form suitable for further data processing and machine learning applications.

# Conclusion
Through this practical, I revised the basic concepts of Pandas and NumPy, including DataFrame creation, NumPy array properties, mathematical and matrix operations, and categorical data encoding.
