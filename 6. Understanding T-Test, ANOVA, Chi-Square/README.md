# Objective

The objective of this practical is to perform statistical analysis and hypothesis testing on the TeachingRatings dataset using Python. The practical covers T-test, One-Way ANOVA, Two-Way ANOVA, Chi-Square Test, and Correlation Analysis using Pearson and Spearman correlation methods.

# What I Did

In this practical, the TeachingRatings dataset was loaded using Pandas and analyzed using statistical functions from SciPy and Statsmodels.

T-Test: Compared teaching evaluation scores between male and female instructors to determine whether gender had a statistically significant effect on evaluation ratings.

One-Way ANOVA: Analyzed whether instructors' beauty scores differed significantly across different age groups.

Two-Way ANOVA: Examined the effects of both age group and gender on beauty scores, along with their interaction effect.

Chi-Square Test: Tested whether there was a significant association between instructors' tenure status and gender.

Correlation Analysis: Examined the relationship between beauty scores and evaluation scores using Pearson and Spearman correlation.
Pearson was used to measure the linear relationship between the original values, while Spearman was used to measure the monotonic relationship using ranked values.
Appropriate p-values were calculated and compared with a significance level of 0.05 to determine statistical significance.

# Conclusion

The practical demonstrated how different statistical tests can be used to analyze relationships, differences, and associations within a dataset. ANOVA helped determine differences in beauty scores across age groups and the effects of multiple factors, while the Chi-Square test examined associations between categorical variables. Pearson and Spearman correlation provided different perspectives on the relationship between beauty and evaluation scores. Overall, the practical provided hands-on experience in applying statistical hypothesis testing and interpreting results using Python.
