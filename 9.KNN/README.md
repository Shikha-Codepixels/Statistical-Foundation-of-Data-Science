# Objective

To implement the K-Nearest Neighbors (KNN) classification algorithm using the Iris dataset and evaluate its performance through various classification metrics and visualizations.

# Dataset

Dataset: Iris Dataset

Target Variable: Species

Features: Sepal Length, Sepal Width, Petal Length and Petal Width.

# Tasks Performed

Exploratory Data Analysis using head(), describe() and groupby().

Feature scaling and preprocessing.

Splitting the dataset into training and testing sets.

Training a KNN classification model using Scikit-learn.

Generating a Confusion Matrix and calculating Accuracy Score.

Generating a Classification Report.

Comparing error rates for different K values.

Plotting error values against K values.

Finding the optimal K value.

Visualizing KNN classification results on the test data.

# Libraries Used

Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

# Conclusion

Successfully implemented the K-Nearest Neighbors algorithm on the Iris dataset. Evaluated model performance using classification metrics, compared error rates for different K values, and identified the optimal K value for classification.
