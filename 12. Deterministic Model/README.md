# Objective

To implement the Metropolis algorithm and explore deterministic modelling using MCMC techniques and parameter estimation.

## Part A – Implement Metropolis Algorithm

Implementing the Metropolis algorithm for sampling from a bimodal probability distribution.

Generating samples using multiple independent Markov chains.

Visualizing the sampling process using trace plots and histograms.

Analyzing chain convergence using the R-hat statistic.

## Part B – Deterministic Model

Implementing a deterministic logistic growth model.

Comparing numerical and analytical solutions.

Generating noisy observations from the model.

Applying the Metropolis algorithm for parameter estimation.

Estimating the growth rate and carrying capacity.

Analyzing posterior distributions, acceptance rates, and credible intervals.

Visualizing the estimated model against observed data.

# Libraries Used

NumPy, Pandas, Matplotlib, SciPy.

# Conclusion

Successfully implemented the Metropolis algorithm for probability distribution sampling and applied it to parameter estimation in a deterministic logistic growth model. Studied convergence, posterior distributions, and model parameter estimates.
