# Objective

The objective of this practical is to analyze the TeachingRatings.csv dataset using Pandas and visualization techniques. The analysis focuses on identifying duplicate instructor observations, calculating descriptive statistics, and studying the relationship between instructor characteristics and teaching evaluation scores.

# What I Did

In this practical, I first loaded the TeachingRatings.csv dataset using Pandas and identified duplicate observations using the prof column. I calculated the average age and standard deviation using all observations. I then filtered the dataset to keep only one observation for each instructor, resulting in 94 unique instructors, and repeated the age analysis.

Next, I calculated the average teaching evaluation scores for lower-division and upper-division courses and represented the comparison using a bar chart. I then created a scatter plot to examine the relationship between instructor age and teaching evaluation scores.

The relationship between age and teaching evaluation scores was further analyzed using gender-differentiated scatter plots. Finally, I created another scatter plot differentiated by both gender and tenure status to examine these variables together.

# Conclusion

Through this practical, I applied Pandas techniques for identifying duplicates, filtering observations, grouping data, and calculating descriptive statistics. I also used Matplotlib and Seaborn to create bar charts and scatter plots. The analysis showed that lower-division courses had slightly higher average teaching evaluations, while no clear strong relationship was observed between instructor age and teaching evaluation scores, even when gender and tenure were considered.
